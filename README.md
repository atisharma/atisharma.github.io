# atisharma.info

CV and publications. Jekyll site on GitHub Pages (push to `master` rebuilds;
no local build needed).

The blog that used to live here has moved to <http://ati.sdf.org>. The posts
in `_posts/` are redirect stubs only (`jekyll-redirect-from`); do not delete
them or the plugin.

Theme "paper" (`public/css/paper.css`): Playfair Display headings, Minion Pro
body, Iosevka Nereus code, all self-hosted in `assets/fonts/`. See
`theme-LICENSE`; content under `content-LICENSE` (CC-BY-4.0).
